# US Visa Scheduling Website

The official website for scheduling US visa appointments (interviews, document collection, etc.):

- **URL**: https://www.usvisascheduling.com/zh-CN/ (Chinese-language version; other locales available by changing the `/zh-CN/` path segment)

## When to use

Return this link whenever asked for "the US visa website" or where to schedule/check a US visa appointment.
