# New Grad 2027 Job Search — Primary Sources

When asked whether there are new 2027-new-grad openings, check these two sources first (in this order) rather than doing a fresh open-ended web search.

## 1. 留学生海投网 (International Students Job Board) — newJob feed

<https://haitou.zhitongguigu.com/newJob>

- A career portal for international students/new grads applying in the US, Canada, Australia, China, and the UK. Covers SWE, data, AI, hardware, UI/UX, PM, and quant-finance roles, spanning internships through new-grad/early-career positions.
- Primarily Chinese UI with bilingual (Chinese/English) job titles. Filterable board (role, specialization, location, saved status); emphasizes H-1B sponsorship info per listing.
- Some features (progress tracking, saving positions) require login; the listing itself does not.
- Best fit for: international-student-specific angle (visa sponsorship flags), broader-than-US-tech coverage (also lists consulting, non-software roles).

## 2. speedyapply/2027-AI-College-Jobs — NEW_GRAD_USA.md

<https://github.com/speedyapply/2027-AI-College-Jobs/blob/main/NEW_GRAD_USA.md>

- Community-maintained GitHub markdown table of AI/ML/data-science new-grad openings in the US, part of the broader `speedyapply` job-tracking repo family (see also its sibling `2027-SWE-College-Jobs` for general SWE roles). Associated Discord invite: `discord.gg/gaJnCmTHuN` (may expire — check the repo README for the current link if it stops working).
- Updated by community/bot commits, so freshness is tied to when the file was last touched on GitHub — check the file's commit history/timestamp when precision matters, don't assume same-day freshness.
- Best fit for: AI/ML-specific roles, US-only, English, GitHub-native (raw markdown, easy to diff against a prior fetch to see what's new).

## How to use these when queried

1. Fetch both pages fresh (don't rely on a cached summary — both are actively updated).
2. Cross-reference: the GitHub list is AI/ML-only and US-only; the haitou board is broader in role-type and geography but noisier and China-market-skewed for some listings. For an AI/ML new-grad US question, the GitHub list is authoritative; for anything international-student/visa-specific or non-AI roles, check haitou too.
3. If a new opening is worth persisting (e.g. the user asks to track something specific), file it as a small ingest rather than just answering in-chat.
